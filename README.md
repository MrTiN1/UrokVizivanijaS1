# УРОКИ ВЫЖИВАНИЯ — производство 2D-мультсериала

Вертикальный (9:16) анимационный мистический сериал для TikTok / YouTube Shorts.
Серия 1 — **«ПОСЛЕДНИЙ АВТОБУС»**, серия 2 — **«ПУСТОЕ МЕСТО»** (оригинальная
вымышленная история).

> **Напоминание для публикации:** в шапке профиля обязательно разместить
> **@natriavpnbot**, в описании ролика — хэштег **#natriavpn**
> (готовый текст: `output/publication_description.txt`).

## Технологический стек

Аудит машины: Linux x86-64, 4 CPU, 15 ГБ RAM, **без GPU**, без Blender.

| Задача | Инструмент | Почему |
|---|---|---|
| Анимация, камера, монтаж, рендер | **Remotion 4 + React + TypeScript** | кадр = функция от времени, детерминированный рендер, всё правится кодом |
| Персонажи | собственный **SVG-риг** (`src/characters`) | псевдо-3D голова (анфас → ¾ → профиль → спина), суставы, мимика, виземы рта, свет (мягкая тень + цветной контровой) |
| Плавность | собственные кривые (bezier, keyframes, шум, follow-through) в `src/animation` | то же, что GSAP/Motion, но детерминированно для покадрового рендера |
| Эффекты | `src/effects/Weather.tsx`, `Atmosphere.tsx` | дождь в 2–3 слоя, брызги, капли на стекле, отражения на мокром асфальте, объёмные конусы света, мерцание ламп, туман, зерно, виньетка, грейд |
| Озвучка | **ElevenLabs eleven_v4** (готовые голоса Brian / Will / Bill) | заметно живее локального TTS; резерв — **Piper** офлайн |
| Тайминги слов, lip-sync | посимвольное выравнивание ElevenLabs → слова и виземы; **Rhubarb** — перекрёстная проверка | |
| Проверка речи | **sherpa-onnx**, русский zipformer | замена Whisper (его модели заблокированы сетью) |
| Музыка и шумы | синтез на **numpy/scipy** | всё оригинальное → нет вопросов лицензий |
| Баннер | **FFmpeg** chromakey + despill → VP9 с альфа-каналом | хромакей убирается без изменения анимации и звука |
| Сведение, кодирование, проверка | **FFmpeg** (loudnorm, ebur128, blackdetect, freezedetect), Pillow/NumPy для анализа кадров | |

Сознательно не использованы: Blender/Grease Pencil (нет GPU, не установлен, сцены в
коде проще переиспользовать), Rive (нужен визуальный редактор), PixiJS (эффекты
сделаны на SVG внутри Remotion — без WebGL на CPU это стабильнее), Whisper
(модели недоступны из сети), OpenCV (анализ кадров для проверок сделан на
NumPy/Pillow). Генерация картинок нейросетями невозможна без GPU — вся графика
векторная и нарисована кодом.

## Рекламный баннер NATRIA VPN

Компонент `src/components/NatriaBanner.tsx` подключает **официальный файл**
`assets/banner/NATRIA_VPN.mp4` (1770×750, 7,2 с, со звуком). Подготовка:
`scripts/banner/prepare_banner.py` удаляет зелёный хромакей (→ `natria_keyed.webm`
с альфа-каналом) и извлекает звук без изменений (→ `natria_audio.wav`).

Настройки в `episodes/episode_01/episode.json` → `banner`:

| Поле | Значение | Смысл |
|---|---|---|
| `at` | 55.0 | время появления (середина 110-секундного ролика) |
| `duration` | 7.2 | длительность (исходная) |
| `speed` | 1.0 | скорость (компонент запрещает > 1,3) |
| `center` | [540, 960] | точно центр кадра |
| `width` | 1140 | ширина на экране, высота по пропорциям (483 px) |
| `source` / `video` / `audio` | пути к файлам | оригинал, вариант без хромакея, звук |
| `minAreaRatio` | 0.25 | минимум видимой площади |

На 9:16 баннер с пропорциями 2,36 : 1 даже во всю ширину кадра занимает 23,8 %.
Чтобы видимая площадь была ≥ 25 %, он чуть шире кадра: по бокам за край уходит по
30 px (2,6 % его ширины; текст и логотипы не задеты). Это согласовано с
владельцем проекта.

Звук баннера вставляется в микс **без изменений** (после нормализации громкости),
музыка и шумы под ним приглушаются почти до тишины; реплик и субтитров в это время
нет. Композиция сцены 5 построена так, что лица персонажей остаются выше баннера.

Проверка по готовому MP4 (`scripts/quality_check/banner_check.py`): время
появления и конца сопоставлением кадров баннера с видео (точность 1 кадр),
центрирование поиском сдвига, видимая площадь по альфа-каналу, отсутствие зелёных
пикселей, отсутствие субтитров и реплик поверх баннера.

## Как собрать серию

```bash
npm install
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
scripts/setup/fetch_models.sh                      # Piper, ASR, Rhubarb (с GitHub)
scripts/produce.sh episode_01 --elevenlabs --preview   # баннер → голоса → субтитры → звук → превью → рендер → QC → соответствие
scripts/produce.sh episode_01 --skip-voices        # пересборка без повторной озвучки
```

Ключ ElevenLabs берётся из переменной `ELEVENLABS_API_KEY` (в этом облачном
окружении его подставляет прокси). Бесплатный тариф: 10 000 символов в месяц, серия
≈ 500 символов; через API доступны только готовые голоса. Готовые MP3 кешируются в
`assets/voices/<серия>/elevenlabs/`, повторная сборка лимит не тратит.
Остаток: `python3 scripts/generate_audio/elevenlabs_tts.py usage`.

Предпросмотр: `npm run studio`. Отдельные кадры:
`node scripts/render/stills.mjs Episode 90,600,1700`. Лист персонажей:
`scripts/render/still.sh BusCastSheet output/cast.png`.

## Как делать следующие серии

1. Написать сценарий в формате `episodes/episode_01/script.txt` и выполнить
   `python3 scripts/parse_script.py script.txt episode_02 --number 2`. Получится
   `episodes/episode_02/episode.json`: сцены, тайминги, реплики, голоса, готовые
   компоненты сцен и **баннер, автоматически поставленный в середину ролика**
   (с окном, где не должно быть реплик).
2. Поправить `at` реплик, `keywords` (жёлтые слова), `music` (настроения `lb_*`),
   `ambience` / `sfx` / `steps` (звуки по таймингу — без программирования).
3. Сцены: `component` указывает на React-сцену. Каст (`BUS_CAST`) и локации
   (`world/City.tsx`, `Places.tsx`, `Bus.tsx`, `Phone.tsx`) переиспользуются; общие
   планы — `AisleShot` (салон, вид вперёд/назад), `GlebWindowShot`, `DriverCabShot`.
   Новую локацию удобно начинать с копии похожей.
4. `scripts/produce.sh episode_02 --elevenlabs --preview` — всё остальное автоматически.

Прошлая серия («Контракт») сохранена в `episodes/legacy_contract` и
`src/scenes/contract`, но в этом сериале больше не используется.

## Ограничения

- Готовые голоса ElevenLabs изначально англоязычные: русский чистый (распознавание
  100 %), но лёгкий акцент возможен. Русские голоса из библиотеки — на платном тарифе.
- Персонажи — векторный cut-out риг, а не покадровая рисованная анимация.
- Сюжет вымышлен.
