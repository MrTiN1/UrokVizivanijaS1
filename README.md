# УРОКИ ВЫЖИВАНИЯ — производство 2D-мультсериала

Вертикальный (9:16) анимационный сериал для TikTok / YouTube Shorts.
Серия 1 — **«ГЛЕБ. КОНТРАКТ»** (вымышленная история).

| Файл | Что это |
|---|---|
| `output/episode_01.mp4` | готовая серия: 1080×1920, 30 fps, H.264 + AAC, 120 с, −14 LUFS, со вшитыми субтитрами |
| `output/episode_01.srt` | субтитры отдельным файлом |
| `output/contact_sheet.jpg` | контактный лист: по 2 кадра из каждого плана |
| `output/qc_report.md` / `.json` | отчёт автоматической проверки качества |
| `output/gleb_model_sheet.png`, `output/cast_sheet.png` | модельный лист Глеба и лист всех персонажей |

## Технологический стек

Выбран по итогам аудита машины: Linux x86-64, 4 CPU, 15 ГБ RAM, **без GPU**;
сеть пропускает npm, PyPI и релизы GitHub, но блокирует HuggingFace,
ElevenLabs, Silero, Vosk и хранилище моделей Whisper.

| Задача | Инструмент | Почему |
|---|---|---|
| Анимация, камера, монтаж, рендер | **Remotion 4 + React + TypeScript** | всё описано кодом, кадр = функция от времени, детерминированный рендер, легко редактировать |
| Персонажи | собственный **SVG-риг** (`src/characters`) | псевдо-3D голова на эллипсоиде (плавный поворот анфас → ¾ → профиль), иерархия суставов, мимика, viseme-рот, фильтр освещения (мягкая тень + цветной контровой свет) |
| Озвучка | **Piper TTS** (нейросетевые русские голоса ruslan / denis / dmitri, MIT/CC) | локально, бесплатно; ElevenLabs недоступен из этой сети |
| Тайминги слов и lip-sync | выравнивание фонем самого Piper | точнее, чем распознавание: точное время каждой фонемы → слова для субтитров и формы рта |
| Lip-sync (резерв) | **Rhubarb Lip Sync 1.13** | для внешних (не TTS) записей голоса |
| Проверка речи | **sherpa-onnx**, русский zipformer (ASR) | замена Whisper (модели Whisper заблокированы сетью): отбор лучших дублей и проверка разборчивости в финальном миксе |
| Музыка и шумы | собственный синтез на **numpy/scipy** (`scripts/generate_audio`) | оригинальная музыка и эффекты без сторонних сэмплов → нет вопросов лицензий |
| Сведение, кодирование, проверка | **FFmpeg** (rubberband, loudnorm, ebur128, blackdetect, freezedetect) | |
| Шрифты | Montserrat, Oswald, Russo One (SIL OFL) | кириллица, жирные начертания |

Сознательно **не** использованы: Blender/Grease Pencil и OpenToonz (тяжёлые
GUI-пакеты, на CPU без GPU рендер в разы медленнее, а сцены в коде проще
править и переиспользовать), Rive (нужен визуальный редактор, автоматизировать
нельзя), DaVinci/After Effects (недоступны в Linux-контейнере без GUI;
цветокоррекция, зерно, виньетка и свечение сделаны в компонентах `src/effects`).
Генерация изображений нейросетями невозможна без GPU и без доступа к
HuggingFace — вся графика векторная, нарисована кодом.

## Структура

```
src/
  characters/   риг: Head.tsx (голова, глаза, брови, рот, волосы, шлем), Body.tsx (торс, руки, ноги, одежда),
                Character.tsx (сборка + освещение), designs.ts (каст), types.ts (поза, эмоции), CharacterSheet.tsx
  animation/    core.ts (ключи, easing, шум, моргание, дыхание), performance.ts (оживление, lip-sync, эмоции),
                cycles.ts (Walk, Run, Nervous, Sit)
  camera/       виртуальная камера: zoom, pan, dolly, shake, параллакс-слои, rack focus (blur)
  effects/      зерно, виньетка, грейд, пыль, дым, туман, искры, лучи света, вспышки
  scenes/       S1Hook … S8EndCard + backgrounds/ (War, Interior, Base)
  subtitles/    анимированные субтитры
  Episode.tsx   монтаж серии
scripts/
  setup/fetch_models.sh            скачивание голосов, ASR, Rhubarb
  generate_audio/generate_voices.py TTS → обработка голоса → тайминги → виземы → ASR-контроль
  generate_audio/build_subtitles.py субтитры (JSON для рендера + SRT)
  generate_audio/build_soundtrack.py музыка + шумы + голоса → сведение, приглушение музыки под речь, −14 LUFS
  render/                          render_episode.sh, stills.mjs (быстрые превью кадров)
  quality_check/                   qc.py, check_mix_intelligibility.py
  parse_script.py                  текстовый сценарий → episodes/<id>/episode.json
  produce.sh                       весь конвейер одной командой
episodes/episode_01/
  episode.json   сцены, тайминги, планы, реплики, голоса, ключевые события (звук и анимация синхронны)
  script.txt     исходный сценарий
assets/          шрифты, текстуры, голоса (voices/episode_01), сгенерированные шумы
```

## Как собрать серию

```bash
npm install
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
scripts/setup/fetch_models.sh          # голоса Piper, ASR, Rhubarb (с GitHub)
scripts/produce.sh episode_01          # озвучка → субтитры → звук → рендер → QC
scripts/produce.sh episode_01 --skip-voices --clean   # + версия без субтитров (output/episode_01_clean.mp4)
```

Предпросмотр в браузере: `npm run studio`. Отдельные кадры:
`node scripts/render/stills.mjs Episode 90,600,1500`.

## Как делать следующие серии

1. Написать сценарий в формате `episodes/episode_01/script.txt` и выполнить
   `python3 scripts/parse_script.py script.txt episode_02` — получится
   `episodes/episode_02/episode.json` со сценами, репликами и голосами.
2. Поправить вручную `at` (когда звучит реплика), `keywords` (жёлтые слова в
   субтитрах), `music` (настроение: tension, calm, neutral, foreboding, cold,
   drama, dark, dark_tail) и `events` (звуковые события).
3. Сцены: `component` указывает на React-сцену. Готовые локации (посадка,
   аудитория, актовый зал, кабинет, учебный центр, кузов грузовика) и весь
   каст переиспользуются; новую сцену удобно начинать с копии похожей.
4. В `src/data.ts` поменять импорты на новую папку серии, затем
   `scripts/produce.sh episode_02`.

Художественные этапы (раскадровка, постановка поз) остаются ручными:
полная автоматизация здесь ухудшила бы качество. Всё остальное — озвучка,
тайминги, lip-sync, субтитры, музыка, шумы, сведение, рендер, проверка —
автоматическое.

## Персонажи

Глеб строится из одного объекта `GLEB_BASE` (лицо, волосы, глаза,
пропорции); варианты одежды (`GLEB_CIVIL`, `GLEB_RECRUIT`, `GLEB_MILITARY`)
меняют только костюм — внешность не может «уплыть» между сценами.
Эмоции: нейтральное, радость, интерес, сомнение, растерянность, тревога,
страх, усталость (+ строгость, шок, грусть для других ролей).
Второстепенные: Артём (одногруппник), представитель ведомства, инструктор,
командир, студенты, новобранцы, военнослужащие.

## Ограничения

- Голоса — локальный нейросетевой TTS: звучат естественно, но не так
  эмоционально, как ElevenLabs. Чтобы заменить на ElevenLabs/живые записи,
  положите WAV в `assets/voices/<ep>/<line_id>.wav`; lip-sync тогда считает
  Rhubarb.
- Персонажи — векторный cut-out риг, а не покадровая рисованная анимация.
- Сюжет вымышлен; это не документальный случай.
