## Баннер NATRIA VPN (проверяется программно по готовому MP4)
- [ ] появляется ровно в 00:55 (измерено по кадрам, допуск 1 кадр)
- [ ] один баннер, строго по центру кадра (измеренный сдвиг ≤ 2 px)
- [ ] видимая площадь ≥ 25 % кадра; пропорции сохранены; по бокам за кадр уходит ~2,5 % ширины баннера (иначе на 9:16 нельзя получить 25 %; согласовано с владельцем)

- [ ] хромакей удалён: зелёных пикселей нет
- [ ] на баннер не наложены субтитры; во время баннера нет реплик
